## 🎤 语音识别 (在线云端, 准确率 95%+)

基于科大讯飞语音听写 SDK, 支持**全局悬浮球**和**搜索页**两个入口。

### 功能

| 功能 | 说明 |
|------|------|
| **全局悬浮球** | 首页右下角蓝色麦克风浮球, App 内任意位置可用 |
| **波形动效** | 录音时麦克风两侧彩色跳动波形条, 状态实时可见 |
| **语音搜索** | 说"搜索刘德华"自动跳转并搜索 |
| **页面跳转** | 说"打开设置"/"排行榜"/"歌单"直接跳转 |
| **播放控制** | 说"播放"/"暂停"/"下一首"/"上一首"控制播放 |
| **自动停止** | 停止说话后自动识别完成, 面板自动收拢 |
| **超时保护** | 15 秒无结果自动退出 |

### 入口

- **首页右下角蓝色麦克风浮球** — 点击唤醒, 全屏语音面板
- **搜索框右侧麦克风图标** — 搜索页内快速语音输入

### 技术栈

- SDK: 科大讯飞 MSC (SpeechConstant)
- 识别模式: 在线云端 (APPID: `472cc4da`)
- 引擎: `libmsc.so` + `Msc.jar`
- 离线模型: `common.jet` + `sms_16k.jet` (保留降级)

### 设置

语音唤醒开关和自定义唤醒词: **设置 → 其他 → 语音唤醒** (后续版本完善)

## 🛠️ 构建

### 本地构建(Android)

```bash
# 安装依赖
npm install

# 生成 JS bundle
npm run bundle-android

# 构建 APK(在 android 目录)
cd android
./gradlew assembleRelease
```

### GitHub Action 自动构建

push 到 `main` 分支自动触发构建,生成的 APK 发布到 GitHub Releases。

需要配置以下 Secrets:
- `MYAPP_KEYSTORE_BASE64`:签名密钥 base64
- `MYAPP_UPLOAD_STORE_FILE`:密钥文件名
- `MYAPP_UPLOAD_KEY_ALIAS`:密钥别名
- `MYAPP_UPLOAD_STORE_PASSWORD`:密钥存储密码
- `MYAPP_UPLOAD_KEY_PASSWORD`:密钥密码
